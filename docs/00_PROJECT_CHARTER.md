# IX-Fusion Project Charter

## Purpose

IX-Fusion is an evaluation-only computational research framework for testing one bounded
question: whether a C6-seeded stellarator starting condition retains any reproducible
advantage after physics and engineering penalties are counted against matched controls.

The project exists to falsify or advance that hypothesis. It does not exist to preserve a
visual motif, manufacture a positive result, or claim that fusion power has been solved.

## Locked research question

> Does a C6-seeded quasi-isodynamic/omnigenous stellarator, co-optimized with distributed
> phase-coherent RF actuation and engineering constraints, provide measurable improvements
> in confinement-related or controllability metrics relative to matched conventional
> stellarator baselines without worsening magnetic islands, transport, stability,
> structural burden, actuator complexity, or whole-system penalties?

The internal release can answer only a lower-authority version of that question. It screens
seed behavior using dimensionless reduced models. High-fidelity equilibrium, coil,
particle, stability, turbulence, RF full-wave, blanket, and plant-power analyses are explicit
future gates.

## Non-negotiable rules

1. Physics wins over the C6 motif. Optimization may erase the motif.
2. A failed hypothesis is a successful research outcome if the failure is reproducible.
3. Conversation-derived numbers are not findings. Repository code must regenerate findings.
4. Unknown stays unknown.
5. Matched controls receive the same optimization budget.
6. Safety, licensing, and claim boundaries are part of the technical architecture.
7. No physical reactor construction or operation instructions are provided by this release.
8. README claims must be written from the finished repository state.
