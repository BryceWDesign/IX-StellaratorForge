# Source Reuse and Concept Provenance Map

IX-Fusion was informed by earlier evaluation repositories supplied by the project owner.
The release implementation is newly written for IX-Fusion; earlier projects are used as
conceptual provenance, not as evidence that their original application transfers to fusion.

| Prior project | Retained abstraction | Explicitly not transferred |
|---|---|---|
| IX-AeroIntegrity | geometry/structural health, sensing, audit discipline | aerospace performance claims |
| IX-Vibe | resonance identification and verification mindset | material/damping claims without fusion validation |
| IX-Legacy | deterministic telemetry, fault/thermal logic, energy truth | ambient harvesting as fusion power |
| Green-Hydrogen | evidence gates, unknown handling, A/B logic | electrolysis hardware as fusion fuel solution |
| Superheavy-Survival-Audit | Monte Carlo, ablation, negative controls, provenance | nuclear-survival domain conclusions |
| IX-Golden-Trump-Card | synchronized multi-source phase control | scalar-field, material-property-transfer, numerology claims |
| IX-TunerCore | distributed actuator/control abstraction | 432 Hz, 3-6-9 lock, scalar convergence claims |
| IX-HfTaZen-Shield | segmented hot-face/health-monitoring architecture | direct material qualification for plasma-facing use |
| IX-GCR-SPE / IX-Shield | geometry-aware protection and weak-zone analysis | spacecraft shielding materials as fusion blanket design |
| OpenCryoCore | sensing/state/fault-control structure | original cooling physics as magnet cryogenic design |
| Toroidal Energy Core Generator | energy-accounting caution only | harvested energy as meaningful fusion gain |
| IX-Trinity | isolated control/fault-domain thinking | domain-specific hardware assumptions |

Sacred-geometry and cymatic imagery are retained only as historical design inspiration.
Physics terms used in IX-Fusion are symmetry, harmonics, eigenmodes, phase, field periods,
and experimentally falsifiable metrics.
