
# Where IX-StellaratorForge Is Now

## Completed

- The original IX-Fusion reduced-order result is preserved rather than rewritten.
- A multi-family scientific search strategy exists.
- SFR-1 Rev A now defines an actual reactor-level system boundary and physical subsystem stack.
- The plant has explicit design targets for scale, magnetic field, HTS regime, radial build, D-T power class, tritium breeding, exhaust, ECRH, thermal conversion, recirculating power, maintenance and safety.
- Exact D-T reaction and simple plant/plasma screening ledgers are executable and tested.
- Every important target is labeled with its authority so the repository cannot quietly convert a target into an achieved result.
- All high-fidelity reactor gates remain explicitly unrun.

## What this means

The project has advanced from **“a computational stellarator hypothesis”** to **“a parameterized preconceptual stellarator reactor architecture with a falsifiable path to selecting its magnetic core.”**

That is a meaningful engineering step, but it is still far upstream of a fusion reactor demonstration.

## The single most important next action

Run G1 as a common-budget high-fidelity equilibrium tournament. Produce finite-beta DESC equilibria for the 3FP, 4FP and 6FP QI-family branches plus the QA reference and direct-J search branch, then independently cross-check promoted finalists with VMEC++.

Until G1 exists, SFR-1 has a reactor body waiting for a validated magnetic heart.

## What would materially change confidence

The first major jump in confidence occurs only when one candidate simultaneously has:

1. a converged finite-beta equilibrium;
2. strong direct orbit/alpha confinement;
3. a coil set that respects the 1.35 m radial target without impossible strain/stress;
4. an edge topology compatible with exhaust and maintenance.

The next jump occurs when full 3-D neutronics and plant power balance close around that same candidate.
