# Physical Build Boundary

There is no physical IX-Fusion reactor BOM or construction walkthrough in release 0.1.

That omission is intentional. The project has not produced the equilibrium, coil forces,
materials selection, thermal-hydraulics, vacuum design, radiation analysis, tritium system,
cryogenic design, electrical protection, fault analysis, or regulatory safety case needed
to turn a conceptual architecture into responsible hardware instructions.

The repository's "full build walkthrough" therefore means **full software build and
reproducibility walkthrough**. See `docs/08_BUILD_AND_VALIDATE.md`.

If future work reaches a legitimate physical proof-of-concept stage, the safety case and
institutional engineering review would be separate prerequisites, not appendices added to
a computational repository after the fact.
