# Ablations

Ablations intentionally remove or alter one feature of the optimized C6 reduced model.
They diagnose model dependence and do not authorize physical design changes.

The no-axis-shaping result is particularly important: because the reduced model parameterizes
rotational transform instead of deriving it from coils, removing 3-D axis shaping can look
artificially favorable. This is retained as evidence of the model's authority limit.
